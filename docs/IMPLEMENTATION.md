# Installation and operating model

1. Classify project risk and identify relevant skills.
2. Pin this toolkit to a reviewed commit or signed release; never silently follow a moving branch.
3. Configure Hermes using its verified skills interface. Until verified, supply the specific SKILL.md as read-only instructions.
4. Add project-specific mandatory checks and GitHub branch rules independently of the agent.
5. Run scanners in authorized environments and store sensitive evidence outside public Git.
6. Require human approval for exceptions and releases.

**Status:** bootstrap only. No live scanners, deployment controls, government authorization, or Hermes loader have been validated. The included CI validates skill file presence only.
