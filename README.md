# Elliyeen Enterprise Security Agent

A versioned **proposed** security engineering toolkit for Elliyeen FDE projects, with 12 modular skills, report templates, and a non-deploying bootstrap GitHub Actions workflow.

**Not a production security audit, scanner, certification, or government authorization.** The workflow validates skill presence only; independent project-specific security checks and branch protections remain necessary.

Read [AGENTS.md](AGENTS.md), [security standard](docs/SECURITY-AGENT-STANDARD.md), and [implementation guide](docs/IMPLEMENTATION.md). Pin a reviewed commit before Hermes installation. Do not commit secrets, CUI, classified information or customer security evidence to this public repository.
